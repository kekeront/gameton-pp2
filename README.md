# X-Day

**Пиксельная стелс-игра**: пронеси торт через 10 комнат школы, избегая студентов с помощью лазерной указки. Собери 9 свечей и доставь торт учителю.

> Проект для хакатона **Gameton PP2** (Programming Principles 2)

## Проблема и решение

**Проблема:** Нужна игра, демонстрирующая владение ООП, модульной архитектурой и Pygame в рамках курса PP2.

**Решение:** Top-down стелс-игра с 10+ уровнями, системой лазерного обнаружения, сбором предметов и анимированными переходами между комнатами. Каждый уровень — отдельная комната школы с уникальной планировкой.

## Быстрый старт

```bash
git clone https://github.com/kekeront/gameton-pp2.git && cd gameton-pp2
pip install -r requirements.txt
python game.py
```

## Архитектура

```
game.py                    # Точка входа, главный игровой цикл
│
├── classes/
│   ├── Player/            # Игрок: движение, анимация 8 направлений
│   ├── Laser/             # Лазерная указка: рейкаст, обнаружение коллизий
│   ├── Cake/              # Торт, следующий за игроком
│   ├── GameMap/           # Базовый класс карты
│   ├── Levels/            # Level2..Level11 — каждая комната
│   ├── MainMenu/          # Экран главного меню
│   ├── GameOverScreen/    # Экран проигрыша
│   └── WinScreen/         # Экран победы
│
├── functions/
│   ├── collision.py       # Детекция столкновений
│   └── getMouseAngle.py   # Угол мыши для лазера
│
└── assets/
    ├── map/               # Тайлы и стены для 11 уровней
    ├── player/            # 24 спрайта (8 направлений x 3 кадра)
    ├── laser/             # Спрайты лазера и эффекта попадания
    ├── students/          # NPC-студенты
    ├── audio/             # Музыка и звуковые эффекты
    ├── UI/                # Меню, game over, переходы
    └── fonts/             # Пиксельный шрифт
```

## Ключевые фичи

- **10+ уникальных уровней** — комнаты школы с разной планировкой стен и препятствий
- **Лазерный рейкаст** — луч отслеживает ближайшее препятствие в реальном времени
- **Стелс-механика** — если лазер попадает на студента, игра окончена
- **Система свечей** — собери все 9 свечей, чтобы открыть финальный портал
- **8-направленное движение** с анимацией и тенью под персонажем
- **Анимированные переходы** между уровнями
- **Оригинальный пиксель-арт** и звуковое оформление
