# Архитектура X-Day

## Обзор

X-Day — top-down стелс-игра на Pygame. Игрок перемещается между комнатами школы, избегая обнаружения студентами через лазерную механику.

## Игровой цикл

```
game.py (главный цикл)
    │
    ├── Обработка ввода (клавиатура + мышь)
    ├── Обновление состояния
    │   ├── Player.move()          — движение + анимация
    │   ├── Laser.move()           — следует за игроком
    │   ├── Cake.move()            — следует за игроком
    │   ├── Laser.detect_collision() — рейкаст к препятствиям
    │   └── Проверка порталов      — переход между уровнями
    ├── Рендеринг
    │   ├── GameMap.update()       — фон + декорации
    │   ├── GameMap.render_collision() — стены + NPC
    │   ├── Player.render()        — с учётом приоритета слоёв
    │   ├── Laser.render()         — луч + эффект попадания
    │   └── UI-экраны              — меню / game over / победа
    └── pygame.display.flip()
```

## Классы

| Класс | Ответственность |
|-------|----------------|
| `Player` | Позиция, 8-направленное движение, анимация, коллизии со стенами |
| `Laser` | Рейкаст от игрока в направлении мыши, обнаружение пересечений с объектами |
| `Cake` | Визуальный объект, следующий за игроком |
| `GameMap` | Базовый класс: загрузка тайлов, управление стенами/студентами/порталами/свечами |
| `Level2..11` | Наследники GameMap с уникальной планировкой каждой комнаты |
| `MainMenu` | Экран главного меню с кнопкой "Play" |
| `GameOverScreen` | Экран проигрыша с кнопкой "Restart" |
| `WinScreen` | Финальный экран победы |

## Механика обнаружения

Лазер выпускает луч от игрока в направлении курсора мыши. Для каждого кадра:
1. Проверяются все препятствия (стены, свечи, студенты)
2. Находится ближайшее пересечение
3. Если ближайший объект — студент, срабатывает Game Over

## Система уровней

Каждый уровень — отдельный класс, наследующий `GameMap`. Уровни соединены порталами.
Свечи (9 штук) распределены по уровням 3-10. Все свечи нужны для открытия портала на уровне 10.
